# MILAN STUDY — V10

نسخة محسنة من MILAN STUDY مع تجربة تفاعلية وإعدادات إشعارات وصوت وPWA.

## التشغيل

```bash
python3 app.py
```

الافتراضي: `0.0.0.0:20047`

إذا كانت قاعدة البيانات القديمة `milan.db` موجودة، لا تحذفها. يتم إنشاء جدول `user_settings` تلقائياً.

## المزايا الجديدة

- إضاءة تفاعلية ووهج خفيف أثناء التركيز.
- حركات دقيقة للأزرار والبطاقات.
- أصوات اختيارية للنقر وبدء/إيقاف/إنجاز جلسة.
- إشعارات المتصفح عند بدء الجلسة وعند مغادرة الصفحة أثناء المؤقت.
- مؤقت مصغر داخل التطبيق + خيار فتح نافذة صغيرة عبر Picture-in-Picture/نافذة منفصلة حسب دعم المتصفح.
- PWA قابلة للتثبيت من المتصفح.
- إعدادات محفوظة لكل مستخدم.
- وضع مانع/حماية تركيز مع اختيار تطبيقات للتذكير.

## ملاحظة عن مانع التطبيقات

تطبيق ويب يعمل داخل المتصفح لا يملك صلاحية حجب تطبيقات Android/iOS الأخرى أو اكتشاف التطبيق المفتوح في النظام. لذلك وضع "مانع التطبيقات" هنا يعمل كطبقة تذكير/حماية تركيز داخل MILAN، وليس كحاجب نظام فعلي. للحجب الحقيقي على Android نحتاج لاحقاً تطبيق Android أصلي بصلاحيات النظام المناسبة.
